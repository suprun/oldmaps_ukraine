## Про плагін

**OldMaps for QGIS** додає до QGIS док-панель із каталогом геоприв'язаних матеріалів [OldMaps.com.ua](https://oldmaps.com.ua/). Каталог об'єднує історичні карти, аерофотознімки та супутникові зображення міст і сіл України за локаціями та часовими періодами.

Вибрані матеріали додаються до проєкту як XYZ-растри. Це дає змогу накладати їх на сучасні базові карти й власні геодані, змінювати прозорість, порівнювати територію в різні роки та досліджувати зміни ландшафту й забудови.

## Можливості

- каталог доступних локацій і шарів у зручному дереві;
- автоматичне завантаження актуальної версії каталогу та робота з локально кешованими даними;
- пошук за назвами локацій і карт;
- відображення максимального рівня масштабування для кожного шару;
- додавання XYZ-шару кнопкою, подвійним клацанням або перетягуванням на полотно карти;
- автоматичне позиціонування карти на межах доданого шару;
- режим фіксації поточного виду під час додавання шару;
- захист від повторного додавання того самого шару;
- перехід до меж вибраної локації або карти;
- повзунок прозорості безпосередньо в легенді доданого шару;
- перегляд атрибуції та посилання на джерело вибраної карти;
- підсвічування меж карти при наведенні на шар у каталозі;
- відображення меж усіх доступних карт на полотні QGIS;
- пошук карт, що покривають указану користувачем точку;
- локальний проксі та дисковий кеш тайлів для стабільнішого й швидшого завантаження;
- ручне оновлення каталогу та очищення кешу через меню **OldMaps**;
- сумісність із QGIS 3.16–4.x та інтерфейсами Qt5/Qt6.

## Вимоги

- QGIS **3.16 або новіший** (підтримується QGIS 4.x);
- доступ до інтернету для оновлення каталогу та завантаження тайлів;
- Windows, Linux або macOS із підтримуваною версією QGIS.

Плагін використовує модулі, що входять до складу QGIS і стандартної бібліотеки Python, тому окреме встановлення Python-залежностей не потрібне.

## Встановлення

### Із ZIP-архіву

1. Завантажте архів `oldmaps_qgis.zip` зі сторінки випуску або репозиторію плагінів.
2. У QGIS відкрийте **Плагіни → Керування та встановлення плагінів**.
3. Перейдіть на вкладку **Встановити з ZIP**.
4. Виберіть завантажений архів і натисніть **Встановити плагін**.
5. Увімкніть **OldMaps for QGIS**, якщо він не активувався автоматично.

> Архів має містити каталог `oldmaps_qgis` як кореневу папку плагіна.

### Через сторонній репозиторій QGIS

Папку `repo`, опубліковану в цьому GitHub-репозиторії, можна підключити до QGIS як сторонній репозиторій плагінів:

1. У QGIS відкрийте **Плагіни → Керування та встановлення плагінів → Налаштування**.
2. У блоці **Репозиторії плагінів** натисніть **Додати**.
3. У полі **Назва** введіть `OldMaps`, а в полі **URL** — адресу:

   ```text
   https://raw.githubusercontent.com/suprun/oldmaps_ukraine/main/repo/plugins.xml
   ```
4. Збережіть репозиторій і натисніть **Перезавантажити репозиторії**.
5. Перейдіть на вкладку **Усі**, знайдіть **OldMaps for QGIS** і натисніть **Встановити плагін**.

### Із вихідного коду

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/suprun/oldmaps.git
   ```
2. Скопіюйте папку `oldmaps_qgis` до каталогу плагінів активного профілю QGIS.
3. Перезапустіть QGIS та увімкніть плагін у менеджері плагінів.

Шлях до каталогу профілю можна знайти в QGIS через **Налаштування → Профілі користувача → Відкрити папку активного профілю**. Плагіни розміщуються в підкаталозі `python/plugins`.

## Як користуватися

1. Натисніть кнопку **OldMaps** на панелі інструментів QGIS — праворуч відкриється док-панель каталогу.
2. Розгорніть потрібну локацію та виберіть карту.
3. Додайте її одним зі способів:

   - натисніть кнопку **Додати вибраний шар на карту**;
   - двічі клацніть назву шару;
   - перетягніть шар із каталогу на полотно QGIS.
4. Налаштуйте прозорість доданого растра в панелі шарів і порівнюйте його з іншими даними проєкту.

Для пошуку матеріалів у конкретному місці увімкніть **Знайти карти в точці** та клацніть на карті. Каталог покаже лише ті шари, чиї межі покривають вибрану точку. Клавіша `Esc` завершує режим вибору, а кнопка скидання прибирає просторовий фільтр.

## Каталог і кеш

Під час відкриття панелі плагін перевіряє актуальність каталогу та допоміжних ресурсів. Завантажені дані й тайли зберігаються в кеші профілю користувача, тому повторне відкриття вже переглянутих матеріалів відбувається швидше.

У меню **Плагіни → OldMaps** доступні команди:

- **Оновити локації** — повторно перевірити й завантажити актуальний каталог;
- **Очистити кеш** — видалити локально збережений каталог, допоміжні ресурси й тайли;
- **Довідка** — відкрити короткий опис інструментів плагіна.

Після очищення кешу каталог і тайли будуть завантажені повторно за потреби.

## Дані та атрибуція

Каталог і тайли надає [OldMaps.com.ua](https://oldmaps.com.ua/). Відомості про джерело зберігаються у властивостях доданого шару. Атрибуцію вибраної карти можна переглянути кнопкою **Атрибуція** або через контекстне меню шару в каталозі.

Права на окремі картографічні матеріали визначаються їхніми першоджерелами. Під час використання й публікації даних дотримуйтеся атрибуції, зазначеної для відповідного шару.
